Controls
  • Hold GRIP - arm follows that hand (release = arm holds)
  • TRIGGER - gripper (squeeze = close)
  • A / X - fine (slow) mode on/off
  • B / Y - send that arm home (when GRIP not held)
  • Click both sticks - set "forward" to where the controllers point
Haptics: short tick = engaged, soft buzz = at reach limit, long buzz = frozen / error.
